# Статус: iam-timuroid-site

## Текущая цель

Развивать личный сайт TIMUROID как портфолио и эксперимент по представлению
опыта в AI-разработке и проверке интереса к консультациям и прототипам.
Текущая формулировка выведена из содержимого сайта и может быть уточнена по
исходному диалогу.

## Готово

- Репозиторий `timuroid/iam-timuroid-site` склонирован в Work; основная ветка — `main`.
- Установлены зависимости под Node.js 24; итоговые `npm run check` и `npm run build` завершились успешно.
- Локальная страница отвечает `HTTP 200` на `http://127.0.0.1:4173`.
- Перестроены разделы, сокращён первый экран, добавлены текущие роли, логотип «Цифровой стали» и видео «LLM на практике». Programmium удалён.
- Переработаны глянцевый живой шар, подсказки и мобильный экран агента с карточками внутри разговора.
- При переходе из карточек микрофон выключается, а фокус переносится к целевому разделу/форме.
- Сайт опубликован на `https://iam.timuroid.ru`: HTTPS 200, HTTP перенаправляется на HTTPS.
- Работает отдельная служба systemd под пользователем `timuroid`, Node.js 24.21.0 и существующий Caddy. Другой сервис сервера остаётся активным.
- Активный выпуск — `/opt/timuroid/releases/20261002-redesign`; предыдущий выпуск, конфигурация Caddy и SQLite backup сохранены.
- Опубликованные CSS/JS/логотип совпадают с локальными исходниками; страницы кейсов и политика возвращают 200, видео — 206 с корректным диапазоном байтов.
- Текстовый агент с серверным ключом ответил и выбрал карточку преподавания `bmstu-teaching`.
- Сохранена короткая документация проекта; SDD-комплект не вводился.

## Ограничения проверки

- Ссылка на исходный диалог недоступна в текущем браузерном сеансе; для точного восстановления идеи нужны выдержки из него.
- Проверка вида страницы, GLSL, реального микрофона, диктовки и мобильной клавиатуры не проведена: инструмент отказал в доступе к браузеру. Проверены исходники, сборка, HTTP-доставка и текстовый API.
- Текстовое разрешение пользователя на просмотр браузера получено, однако
  инструмент продолжает отклонять локальный сайт и референсы по сохранённому
  запрету. Визуальная проверка новой версии на компьютере и телефоне не выполнена.
- На iPhone добавлен настоящий `checkbox switch` для системного отклика
  микрофона; произвольная вибрация кнопок использует доступный Vibration API.
  Работа на физическом устройстве ещё не проверена.
- Админка и уведомления о заявках не созданы. Форма сохраняет данные в SQLite.
