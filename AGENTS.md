# Работа над TIMUROID

Основной репозиторий: https://github.com/timuroid/iam-timuroid-site. Проект поддерживается в локальном Codex и облачном Codex через GitHub. Целевой хостинг — VPS для `iam.timuroid.ru`. `.openai/hosting.json` — метаданные прежнего Sites-проекта; их наличие не означает запрос на публикацию в Sites.

## Запуск и проверка

- Node.js 24, `npm ci` для зависимостей.
- `npm run dev` собирает проект и запускает `http://127.0.0.1:4173`.
- `.env` необязателен; настройки также читаются из переменных окружения. Ключ OpenAI нужен только для функций агента и диктовки.
- После изменения контента или HTML выполните `npm run build` и обновите страницу. CSS и браузерные JS в режиме разработки читаются с диска.
- Перед передачей изменений: `npm run check`, `npm run build`, `git diff --check`. Проверяйте соответствующее поведение; не добавляйте тесты, повторяющие простую правку текста.
- Подробный совместный процесс: `docs/WORKFLOW.md`. Развёртывание VPS: `deploy/README.md`.

## Содержание и визуальный стиль

- Это личный сайт Тимура, а не лендинг агентства. В начале показывайте его роли: руководство AI-разработкой в «Цифровой стали», исследования и преподавание в МГТУ им. Баумана. Сотрудничество следует после знакомства, опыта и проектов.
- Сохраните блок «За решениями — опыт и любопытство». Пишите кратко, без лишних лозунгов, мелких подписей и повторяющихся кнопок агента.
- Контент и знания агента: `content/site.json`. Демонстрационные кейсы помечайте явно; не выдавайте придуманные результаты, сроки, даты или метрики за факты. Источники логотипов: `content/logo-sources.json`.
- Светлый фон, тёплый коричневый шрифт и глубокий тёмно-синий акцент. Живой шар остаётся одноцветным, блестящим, с изменением формы и отделяющимися частицами; уважайте reduced motion и производительность мобильных устройств.
- Агент открывается в простой стеклянной панели. Голос и диктовка запускаются явным действием; освобождайте микрофон при закрытии и не включайте два режима одновременно.

## Изменения и секреты

- Начинайте отдельную ветку от актуального `main`. Сохраняйте чужие изменения; не делайте force push. Не ведите одну ветку одновременно с компьютера и из облака.
- Не коммитьте `.env`, API-ключи, пароли, SSH-ключи, базы заявок, аудио, cookies или состояние браузера. Не печатайте их в логах. Настоящий ключ хранится только на сервере или в локальном/облачном окружении.
- Заявки хранятся в SQLite (на прежнем Sites — D1). Отправка формы не рассылает уведомления; не обещайте их без реализации.
- GitHub push сам по себе не развёртывает сайт. Выполняйте публикацию по явному запросу пользователя. На VPS сначала проверяйте существующие службы и домены; изменяйте только ресурсы TIMUROID, сохраняйте данные и резервные копии конфигурации. Не трогайте другие машины.
