# Развёртывание проекта

В этом каталоге находятся шаблоны контейнеризации, обратного прокси и серверного окружения. Перед установкой адаптируйте их к выбранному хостингу. Фактические параметры инфраструктуры и данные доступа храните отдельно от публичного репозитория.

Для установки используйте проверенную версию исходников. Проверьте требования вашего хостинга к Docker Compose, домену и сертификату. Голосовой интерфейс опубликованного сайта требует HTTPS.

Ключ OpenAI должен быть доступен только серверному процессу. Создайте закрытый файл настроек по приложенному примеру или используйте защищённые переменные среды своего хостинга. Ключи, пароли и пользовательские базы через GitHub не передаются.

Перед изменением существующей установки сохраните конфигурацию и данные. Применяйте шаблоны только к ресурсам этого приложения. При обновлении сохраняйте базу заявок и проверяйте совместимость миграций.

После установки проверьте страницу, проекты, форму связи, текстового агента, голосовой разговор и диктовку. Для проверки функций OpenAI нужен действующий серверный ключ и доступ к API.

Автоматическая публикация из GitHub в этом проекте не настроена. Развёртывание выполняется отдельно от сохранения исходников. Подробную инструкцию с параметрами конкретного сервера храните в закрытой документации своей инфраструктуры.
