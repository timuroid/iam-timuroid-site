# Карта проекта

Единый Git-корень приложения — корень этого репозитория. Origin:
`https://github.com/timuroid/iam-timuroid-site.git`, основная ветка — `main`.

| Путь | Назначение |
|---|---|
| `public/` | Статическая страница, стили, браузерный агент, голос и диктовка |
| `public/media/` | Видео «LLM на практике» и постер; источники в `content/logo-sources.json` |
| `content/` | Тексты сайта, кейсы и данные для знаний агента |
| `server/` | Node.js API, работа с OpenAI и SQLite |
| `server/media.mjs` | Потоковая доставка видео/постера с HEAD и HTTP Range |
| `db/`, `drizzle/` | Схема данных и миграции |
| `deploy/` | Рабочие systemd/Caddy конфигурации и альтернативные Docker/nginx шаблоны |
| `docs/WORKFLOW.md` | Локальная работа и передача изменений через GitHub |

Проект рассчитан на Node.js 24. На VPS работает `timuroid.service`: код в
`/opt/timuroid/current`, SQLite в `/var/lib/timuroid/timuroid.sqlite`, закрытая
конфигурация в `/etc/timuroid.env`. Caddy направляет `iam.timuroid.ru` на
`127.0.0.1:4318`; HTTPS обслуживает Caddy. Docker/nginx здесь не запущены.

Сборка пересоздаёт только производную папку `dist/media` и копирует туда
`public/media`; видео не включается в base64-бандл. Доставка медиа работает
через Node-обёртку, а не через отдельно развёрнутый Worker.

Когда агент открыт, действия сайта показывают карточки внутри диалога.
Посетитель отдельно переходит к разделу или редактируемому черновику формы;
автоматической отправки заявки агентом нет. При закрытии панели и переходе
на страницу микрофон освобождается. Админка и уведомления о заявках не созданы.

Панель начинает новый разговор после закрытия. Поколения запросов и отмена
защищают новый сеанс от запоздавших ответов старого; переключение между
текстом и голосом внутри открытой панели сохраняет контекст. Подсказки находятся
вне текстового composer: доступны в голосе и сменяются в простое каждые 8 секунд.

Микрофон: echo cancellation и noise suppression включены, автоматическое
усиление выключено. Realtime использует `far_field` noise reduction,
server VAD threshold 0.65 и паузу 800 мс. Эти начальные настройки уменьшают
ложные срабатывания; настройка под реальные устройства ещё требует проверки.
Визуальный измеритель шара имеет отдельный порог и плавное затухание, он не
управляет распознаванием речи. Схема настроек: [OpenAI VAD](https://developers.openai.com/api/docs/guides/realtime-vad)
и [Create call](https://developers.openai.com/api/reference/resources/realtime/subresources/calls/methods/create).

`public/haptics.js` централизует необязательный отклик `navigator.vibrate`
с проверкой настоящего нажатия и защитой от двойного вызова. Safari создаёт
системный tick при прямом нажатии видимого переключателя микрофона `switch`;
скрытые элементы и синтетические нажатия для вибрации не используются.
